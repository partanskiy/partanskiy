# Profile repository

Этот репозиторий оформляет личный профиль partanskiy на GitHub.

## Публикация

Поддерживать только одну ветку main и ровно один коммит в её истории.
При каждом обновлении сохранять это условие. Перезапись единственного коммита
явно разрешена владельцем.

## Содержание

Профиль должен быть прежде всего об Илье и его интересах: аниме, математика,
программирование и всё вокруг них. Не превращать его в перечень последних
рабочих задач, стеков или клиентских конфигураций. Название продукта: neurolegal.

Личные ссылки добавлять только по подтверждённым адресам. GPG должен вести
на keys.openpgp.org по полному отпечатку, без копии ключа в репозитории.
Использовать обычную пунктуацию, прямые кавычки и дефисы. Не добавлять эмодзи,
декоративные Unicode-символы, длинные тире и фигурные кавычки.
